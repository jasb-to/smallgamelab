# Small Game Lab

Small games. Big distribution.

Small Game Lab is an independent game studio focused on tiny, highly replayable games with obsessive execution and broad distribution.

## Initial build

- Home — studio landing page
- Games — game catalogue
- Game 001 — Last Stand prototype
- Studio — company story
- Operators — B2B distribution and integration concept

## Build philosophy

Prototype fast. Make the core loop excellent. Measure. Iterate. Publish winners.
