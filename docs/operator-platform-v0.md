# Small Game Lab Operator Platform v0

Sandbox-only B2B integration experience. No live-money wallet, settlement, or regulated gambling functionality.

## Flow
1. Authenticate player session
2. Request balance
3. Launch game
4. Record round
5. Return result
6. Surface analytics

## Surfaces
- `/operators`
- `/operators/simulator`
- `/dashboard`
- `/games/last-stand`
