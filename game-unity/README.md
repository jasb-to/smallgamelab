# The Long Run — Unity Production Game

Stage 1 production foundation for Small Game Lab's Mara game.

## Engine

Unity 6.3 LTS (`6000.3`). Unity recommends 6.3 LTS for productions locking a stable version, with support through December 2027.

## Creative target

A premium 2D side-scrolling run-and-gun inspired by the feel of classic arcade action and the energy of Bombastic Brothers, while remaining an original Small Game Lab IP.

## Stage 1 vertical slice

- Mara movement, jump and double jump
- dash
- aiming and firing
- three weapon identities
- enemy base architecture
- camera follow
- hit points / damage / knockback
- XP and level progression
- upgrade choices
- wave director
- mobile input abstraction
- deterministic game-state boundaries
- asset/license ledger

## Asset policy

Free and purchased Unity Asset Store assets may be used for supporting environment, VFX, audio and production infrastructure. Mara, signature weapons, major enemies, bosses and story-critical art must be original or explicitly licensed for commercial modification.

See `Assets/Documentation/ASSET_LEDGER.md`.
