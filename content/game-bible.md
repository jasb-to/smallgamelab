# The Long Run — Game Bible

The five games are chapters of one playable story. The player follows Mara Vale from courier to the person who can expose the blackout.

## Shared systems
- Mara character controller and visual identity
- Chapter progression state
- Story inventory
- Character upgrades
- Achievements / milestones
- Shared save slot
- Shared audio and visual language
- Mobile touch control abstraction

## Chapter 01 — Rooftop Runner
Core loop: run → jump → slide → evade → deliver.
First objective: get the data shard across the lockdown perimeter.

## Chapter 02 — One More Room
Core loop: enter room → fight → choose upgrade → unlock door.
Carry-forward: data shard points to the relay.

## Chapter 03 — The Getaway
Core loop: drive → drift → evade → boost → escape.
Carry-forward: Inspector Voss is actively hunting Mara.

## Chapter 04 — Dungeon Dash
Core loop: explore → survive → discover → unlock.
Carry-forward: Mara discovers the blackout network.

## Chapter 05 — Street Heat
Core loop: route → deliver → evade → protect package → finish.
Finale: Mara delivers the network key and exposes the origin of the blackout.

## Product rule
Every chapter must be fun before its story layer is added. Story amplifies the game; it does not compensate for weak mechanics.
